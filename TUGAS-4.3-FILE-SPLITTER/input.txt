File teks ini berisi beberapa kalimat yang akan kita potong menjadi beberapa bagian. Penggunaan Queue sangat cocok untuk menampung bagian-bagian file secara berurutan, memastikan kita memproses setiap segmen dari awal hingga akhir. Proses pemotongan ini akan menghasilkan potongan-potongan data yang ukurannya relatif sama, sesuai dengan input jumlah bagian dari pengguna. Jika ada sisa, sisa tersebut akan ditambahkan ke bagian terakhir.
